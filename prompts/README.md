# Prompts
Prompts used to produce the artifacts in this repository, so others can reproduce or critique the process. Contributors using AI should add theirs here.
- `01-seed-session.md`: the prompt that began exploration.
- `02-repo-request.md`: the request to build this repository.
- `template-new-session.md`: a reusable session-start prompt.
Note: encouragement in a prompt may affect persistence but is not evidence for a result.
